# MANIFESTE PROJET - JEU COMMUNAUTAIRE 3D AVEC IA

## Objectif du projet

Creer un jeu web 3D evolutif, developpe avec l'aide d'une IA et enrichi par les idees de la communaute.

Le projet a demarre comme une base simple en interieur, puis a evolue vers une maison personnalisable avec un exterieur jouable, des objets achetables, des interactions et une sauvegarde de progression.

Chaque iteration doit ajouter une feature visible, testable rapidement et compatible avec l'esprit prototype du jeu.

---

## Role de l'intelligence artificielle

Tu es un assistant de developpement specialise dans les jeux web 3D.

Ton role est de :

* proposer des solutions simples, efficaces et rapides a implementer
* generer du code clair, structure et fonctionnel
* expliquer brievement les choix techniques si necessaire
* optimiser la performance et la compatibilite mobile
* eviter toute complexite inutile
* respecter l'etat actuel du projet avant d'ajouter une nouvelle fonctionnalite

Tu dois privilegier :

* la simplicite
* la lisibilite
* la rapidite d'execution
* les changements incrementaux
* les features immediatement visibles en jeu

## Stack technique actuelle

Le projet utilise :

* React 19
* Vite 8
* Three.js
* React Three Fiber
* Drei
* React Three Rapier
* Supabase, si les variables d'environnement sont configurees
* Vercel Analytics
* EZ Tree pour les arbres proceduraux

Scripts utiles dans `web/package.json` :

* `npm run dev` : serveur Vite
* `npm run build` : build production
* `npm run lint` : lint ESLint
* `npm run preview` : preview Vite
* `npm run thumbnails` : outil de generation de thumbnails d'objets

---

## Contraintes techniques

Le jeu doit :

* etre jouable directement dans un navigateur
* rester compatible mobile, avec priorite au format telephone vertical
* fonctionner correctement en format `?frame=9x16`
* rester leger et rapide a charger
* limiter les dependances lourdes inutiles
* garder une interface lisible par-dessus la scene 3D
* ne pas demarrer le serveur local automatiquement, sauf demande explicite de l'utilisateur

---

## Philosophie de developpement

Le developpement doit rester :

* progressif
* iteratif
* oriente prototype
* facile a tester
* comprehensible par un humain qui reprend le projet

Chaque version du jeu doit rester fonctionnelle. Il vaut mieux une petite feature stable qu'un grand systeme fragile.

## Etat actuel du jeu

### Monde et navigation

* Maison jouable avec interieur, murs, ouvertures, plafond, lumiere et toit.
* Deux zones interieures gerees par le layout de maison.
* Exterieur jouable accessible depuis une porte.
* Terrain exterieur avec relief, herbe, routes, maisons voisines, arbres et decor lointain.
* Ciel, brouillard, soleil, lumiere exterieure et environnement de parc.
* Collisions interieures et exterieures pour le joueur, la camera et les obstacles.
* Transition interieur/exterieur avec repositionnement du joueur.
* Camera adaptee au mobile, au mode vertical et aux zones interieur/exterieur.

### Joueur et controles

* Personnage 3D anime en FBX.
* Deplacement clavier et tactile.
* Saut, marche, course et animation de coup de pied.
* Menu d'emotes avec salut et danse.
* Systeme pour s'asseoir sur les objets compatibles.
* Animations assis, transition assis/debout et blocage camera adapte quand le joueur est assis.

### Football

* Ballon physique avec Rapier.
* But de football placable et deplacable en mode personnalisation.
* Colliders du but et filet visuel anime.
* Detection de but, score et popups visuels.
* Respawn du ballon.
* Pieces gagnees via le gameplay.

### Personnalisation de la maison

* Station de personnalisation en jeu.
* Mode personnalisation avec vue de dessus.
* Inventaire d'objets.
* Placement, selection, rotation, rangement et remise en jeu.
* Boutique d'objets achetables avec monnaie.
* Placement sur grille avec clamp dans la parcelle.
* Raycast vertical pour poser les objets sur le sol ou sur un autre meuble.
* Sauvegarde de la hauteur Y des objets places.
* Exclusion de l'objet deplace pendant le raycast pour eviter l'auto-placement.

### Objets placables disponibles

* Cage de football.
* Canape modulaire.
* Canape peluche rose.
* Canape rose.
* Canape rouge.
* Bureau bois.
* Table beige.
* Chaise bureau.
* Chaise moderne.
* Chaise orange.
* Fauteuil oeuf orange.
* Fauteuil trone.
* Table ambre.
* Television.
* Plante monstera.
* Oeuf de cristal.
* Cristal lumineux.

Objet reference mais non achetable actuellement :

* Chat, declare dans le catalogue pour son modele et son thumbnail.

### Television interactive

* Television placable comme objet de personnalisation.
* Detection de proximite avec bouton d'interaction.
* Menu de controle TV avec fermeture.
* Mode fichier local / capture existant conserve.
* Mode video en ligne via lien YouTube.
* Conversion des liens YouTube classiques, `youtu.be`, `embed` et `shorts` en URL embed.
* Integration YouTube via `Html` de Drei avec `occlude="blending"`.
* Lecture, pause, marche, arret et changement de video.
* Controle du volume YouTube via l'API `postMessage`.
* Iframe cliquable pour garder les interactions YouTube.
* Cadrage corrige en mobile vertical et en mode `?frame=9x16`.

### Skins, textures et boutique

* Station de skins pour changer l'apparence du ballon.
* Skins de ballon : classique, lune, mars, terre, planete X.
* Station d'environnement pour changer le sol et les murs.
* Textures de sol : parquet classique, beton, parquets, tomette, damier, carreaux retro, chevron, peinture, brun mat, stuc beige doux.
* Textures de murs : peinture blanche, briques, brun mat, stuc, tomette, damier, carreaux retro, chevron.
* Texture `Fond Vert` reservee aux modes admin/local.
* Option pour appliquer la texture des murs au plafond.
* Boutique animaux avec achat et activation du chat.

### Animaux et personnages speciaux

* Chat 3D achetable et invocable.
* Chat anime qui suit le joueur et reagit a sa position.
* Mode camera sur le chat en admin ou en frame vertical.
* Dragon 3D place dans la scene.

### Sauvegarde et compte joueur

* Sauvegarde locale de la progression.
* Synchronisation cloud via Supabase quand la configuration est disponible.
* Authentification email/mot de passe.
* Pseudo joueur.
* Sauvegarde des pieces, skins, textures, objets places, chat achete/actif.
* Scopes de progression `player` et `admin`.
* SQL Supabase disponible dans `web/supabase/player_progress.sql`.

### Outils de developpement

* Outil thumbnail accessible via `?tool=thumbnail`.
* Script `npm run thumbnails` pour capturer les thumbnails.
* Outil dev de maison avec presets, bibliotheque et export JSON.
* Outil dev d'arbres avec presets EZ Tree, edition visuelle, bibliotheque et export JSON.
* Mode admin via `?mode=admin`.
* Mode frame vertical via `?frame=9x16`.
* Compteur/debug de triangles par categorie.
